# Weather Forecast Application

## Project Overview

The Weather Forecast Application is a Python-based GUI application developed using Tkinter. It allows users to search for weather information by entering a city name and displays detailed weather data such as temperature, humidity, wind speed, pressure, and weather conditions.

The application fetches real-time weather information from an online weather service and presents it through an easy-to-use graphical interface.

---

## Features

* Search weather by city name
* Display current temperature
* Display humidity percentage
* Show wind speed information
* Show atmospheric pressure
* Display weather conditions
* 5-day weather forecast
* Temperature unit conversion (Celsius/Fahrenheit)
* User-friendly graphical interface
* Error handling for invalid input and network issues
* Compatible with Python 3.15

---

* Python 3.15

## Running the Application

Execute the following command:

```bash
python weather_app.py
```

The Weather Forecast Application window will open.

---

## How to Use

1. Launch the application.
2. Enter a city name.
3. Select the temperature unit:

   * Celsius
   * Fahrenheit
4. Click the Search button.
5. View current weather information and forecast details.
